# Heatmap-Assisted Diagnosis

Code and study materials for evaluating whether Grad-CAM heatmaps from fine-tuned
chest X-ray classifiers help radiologists during diagnosis. Models are trained and
evaluated on two datasets — **VinDr-CXR** (28 findings) and **ChestDR** (19 findings)
— and the resulting heatmaps are used in a reader study comparing radiologists'
diagnoses with and without heatmap assistance.

## Repository layout

Only the directories below are tracked in git; everything else (raw data, model
checkpoints, logs, experiment archives) stays local — see [.gitignore](.gitignore).

```
.
├── *.py                     # training, evaluation, and heatmap generation scripts
├── utils/                   # helper functions used by the top-level scripts
├── configs/                 # JSON configs (one per model/dataset run)
├── final/                   # final heatmaps used in the reader study, per dataset
└── cxr_heatmap_reader_app/  # web app used to run the radiologist reader study
└── results/                 # Look below for more details
```

### Top-level scripts

| File | Purpose |
|---|---|
| `train.py` | Trains a classifier (Ark, EVA, RadDINO, CheXzero, or from-scratch) on VinDr-CXR or ChestDR, driven by a config from `configs/`. |
| `eval.py` | Evaluates a trained checkpoint against a config-specified dataset (F1, Hamming loss, AUROC, average precision). |
| `heatmap_final.py` | Generates the final Grad-CAM heatmaps from a trained checkpoint — the source of the images in `final/`. |
| `plot_checkpoint_comparison.py` | Builds ROC and AUROC comparison plots across checkpoints. |
| `stats.py` | Computes per-dataset image mean/std for normalization. |
| `dataset.py` | PyTorch `Dataset` for VinDr-CXR (28 classes). |
| `dataset_chestdr.py` | PyTorch `Dataset` for ChestDR (19 classes). |

### `utils/`

| File | Purpose |
|---|---|
| `model_selection.py` | Builds/loads the backbone models (Ark, EVA, RadDINO, dinov2, CLIP-based). |
| `custom_scheduler.py` | Cosine-annealing warm-up-restart LR scheduler. |
| `focal_loss.py` | Focal loss for multi-label classification. |
| `generate_cam.py` | Grad-CAM generation for a single model/image. |
| `generate_cam_average.py` | Grad-CAM generation averaged across models, for a batch. |
| `generate_cam_average_single_image.py` | Averaged Grad-CAM generation for a single image. |
| `save_image.py` | Saves a heatmap/array as an image file. |
| `build_heatmap_csv.py` | Builds the CSV manifests used to drive heatmap generation. |

### `configs/`

JSON configs consumed by `train.py`, `eval.py`, and `heatmap_final.py` — one per
model/dataset combination (e.g. `ark.json` / `ark_chestdr.json`,
`eva_ft.json` / `eva_ft_chestdr.json`, `rad_dino_ft.json`, `chexzero_ft.json`,
`from_scratch.json`), plus `eval.json` and `heatmap.json` for evaluation and
heatmap-generation runs.

### `final/`

The final Grad-CAM heatmaps used in the reader study, split by dataset
(`chestdr/`, `vindr/`) and then by model (`ark/`, `eva/`, `raddino/`, plus `raw/`
for the unannotated source images), with a per-model CSV of case-level info. Each
CSV's `image_id` column is the original dataset ID (e.g. `final/vindr/ark_vindr.csv`
uses the original VinDr-CXR `image_id`), so heatmaps can be matched back to the
source dataset via that column.

### `cxr_heatmap_reader_app/`

The standalone web app used to run the radiologist reader study
(`Open_CXR_Heatmap_Reader_Study.html`). For each case, a radiologist gives an
initial diagnosis from the chest X-ray alone, then is shown the Grad-CAM heatmaps
from all three models and gives a second diagnosis, confidence rating, and
heatmap-helpfulness rating. Includes the case manifest, image assets,
`tools/make_manifest.py` to regenerate the manifest from a results CSV, and a
`Radiologist_Quick_Start_Manual.txt` for study participants.

### `results/`

The responses exported from the reader app, with each case's ground-truth
diagnosis from the original dataset added:

| File | Contents |
|---|---|
| `R001`–`R005_cxr_gradcam_reader_study_responses_with_gt.csv` | One file per radiologist: 100 rows (50 ChestDR + 50 VinDr-CXR cases). |
| `all_readers_with_gt.csv` | All five readers combined (500 rows). |

The files are generated by `csvs/add_ground_truth.py` (local only). It links each
`case_id` to its source image as follows:

1. `case_id` (e.g. `chestdr_sample_0005`) is `<dataset>_sample_<sample_count>`,
   matching the `dataset` and `sample_count` columns of the per-model case CSVs
   (`ark_<dataset>.csv`, `eva_<dataset>.csv`, `raddino_<dataset>.csv`). The
   sample → image mapping is the same for all three models.
2. That row's `image_id` is the image's ID in the original dataset.
3. The `image_id` is looked up in the original label file
   (`chestdr_published_19d.csv` for ChestDR, `image_labels_test.csv` for VinDr-CXR)
   to get the ground truth.

#### Finding the original image

Use `original_dataset` and `original_image_id`:

| `original_dataset` | `original_image_id` example | Original file | Local copy |
|---|---|---|---|
| `ChestDR` | `5B41558719CFCA.png` | Filename in the ChestDR images (MedFMC); labels in `chestdr_published_19d.csv` (`img_id` column). | `chestdr/images/<original_image_id>` |
| `VinDr-CXR` | `d5bce42a9f926d6fd3b968164bab99b2` | `test/<original_image_id>.dicom` in the VinDr-CXR release on PhysioNet; labels in `image_labels_test.csv` (`image_id` column). | `data/test/<original_image_id>.jpg` |

All VinDr-CXR cases come from the official test split.

#### Original columns (exported by the reader app)

| Column(s) | Description |
|---|---|
| `study_id`, `participant_id`, `experience_years`, `site_code`, `session_code`, `session_created_at` | Study and reader/session metadata (`participant_id` is `R001`–`R005`). |
| `case_id`, `case_order`, `cxr_path`, `first_opened_at` | Case identifier (`<dataset>_sample_<NNNN>`), position in the reader's randomised order, image shown, and time it was opened. |
| `initial_diagnoses`, `initial_diagnosis_count` | Diagnoses from the X-ray alone, `;`-separated. |
| `initial_confidence`, `initial_confidence_label`, `initial_submitted_at`, `initial_response_time_ms` | Confidence (1–5) and timing for the initial read. |
| `assisted_started_at` | When the heatmaps were shown. |
| `post_diagnoses`, `post_diagnosis_count`, `post_confidence`, `post_confidence_label`, `post_submitted_at`, `post_response_time_ms` | The same fields for the heatmap-assisted read. |
| `diagnosis_set_changed`, `confidence_changed` | Whether the diagnoses or the confidence changed after seeing the heatmaps. |
| `helpful_heatmap_choices`, `helpful_heatmap_slots`, `helpful_heatmap_labels`, `helpful_heatmap_model_ids`, `helpful_heatmap_none_selected`, `helpful_heatmap_count` | Which heatmaps the reader found helpful, as on-screen slot and as model (`ark`, `eva`, `raddino`). |
| `heatmap_slot_{1,2,3}_model_id`, `heatmap_slot_{1,2,3}_src` | Model and image shown in each slot (the order is randomised per case). |
| `completed` | Whether the case was completed. |
| `initial_has_<finding>`, `post_has_<finding>`, `changed_<finding>` | One true/false column per finding for the initial read, the assisted read, and whether it changed. |

`<finding>` is one of: `none_of_these_findings`, `tuberculosis`, `atelectasis`,
`calcification`, `consolidation`, `fibrosis`, `nodule`, `pleural_effusion`,
`pneumonia`, `pneumothorax`, `thickened_pleura`, `lung_opacity`, `lung_cavity`,
`pulmonary_edema`.

#### Added columns

| Column | Description |
|---|---|
| `original_dataset` | Source dataset: `ChestDR` or `VinDr-CXR`. |
| `original_image_id` | The image's ID in the source dataset (see above). |
| `ground_truth` | True diagnoses, `;`-separated, using the same 13 finding names readers chose from, so it compares directly with `initial_diagnoses` / `post_diagnoses`. |
| `ground_truth_all_labels` | Every positive label in the original dataset, including findings that were not options in the study (e.g. `fracture_old`, `Cardiomegaly`). |
| `gt_has_<finding>` | One true/false column per finding (same `<finding>` names as above), for per-finding comparison with `initial_has_*` / `post_has_*`. |

Original labels were mapped to the study names as follows; all other labels
appear only in `ground_truth_all_labels`.

| Study finding | ChestDR column | VinDr-CXR column |
|---|---|---|
| Tuberculosis | `TB` | `Tuberculosis` |
| Atelectasis | `atelectasis` | `Atelectasis` |
| Calcification | `calcification` | `Calcification` |
| Consolidation | `consolidation` | `Consolidation` |
| Fibrosis | `fibrosis` | `Pulmonary fibrosis` |
| Nodule | `nodule` | `Nodule/Mass` |
| Pleural effusion | `pleural_effusion` | `Pleural effusion` |
| Pneumonia | `pneumonia` | `Pneumonia` |
| Pneumothorax | `pneumothorax` | `Pneumothorax` |
| Thickened pleura | `thickened_pleura` | `Pleural thickening` |
| Lung opacity | – | `Lung Opacity` |
| Lung cavity | – | `Lung cavity` |
| Pulmonary edema | `pulmonary_edema` | `Edema` |

Notes for scoring:

- Every case has at least one of the 13 findings, so `gt_has_none_of_these_findings`
  is always false.
- ChestDR has no Lung opacity or Lung cavity labels, so those are always false for
  ChestDR cases.
- One response (R003, first case) uses `No finding` rather than
  `None of these findings`.
